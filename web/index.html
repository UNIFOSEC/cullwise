Application Security · SARIF · AI

Turn scanner noise into a prioritized fix list.

Cullwise is an AI-assisted application-security triage tool. It takes the flood of findings from code scanners, de-duplicates them, clusters them into vulnerability classes, and prioritizes what actually matters — optionally using an LLM to judge severity, flag false positives, and write remediation.

What it is

Less noise. Fewer tickets. Faster fixes.

Security scanners (Semgrep, CodeQL, Trivy…) produce hundreds of findings with heavy duplication and false positives. Cullwise automates the first, most tedious pass of triage so engineers see signal, not spam.

🧭 Ingest anything

Reads Semgrep JSON or SARIF 2.1.0 — the standard every major scanner emits — so one tool covers the ecosystem.

🧬 Cluster by class

Groups findings into vulnerability classes (SQL Injection, Hardcoded Credentials, Weak Crypto…) so you fix a category, not 30 tickets.

🤖 Prioritize with AI

Optionally uses Claude to adjust severity, flag likely false positives, and suggest fixes — hardened against prompt injection.
